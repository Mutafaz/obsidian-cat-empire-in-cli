## Re-run the defect probes

```powershell
python 'Obsidian/Cat Empire In CLI/Bugs and Possible Fixes/Evidence/run_audit_probes.py'
```

The runner rebuilds the existing core harness with `tools/validate_core.py`, appends `Evidence/audit_probes.luau` in an OS temporary directory, executes the local `.tools/luau/luau.exe`, and writes its compact report beside the runner. No game source is edited. Existing ignored `.tools` harnesses are regenerated by the established validator. No network or live Roblox stores are used by these probes.
